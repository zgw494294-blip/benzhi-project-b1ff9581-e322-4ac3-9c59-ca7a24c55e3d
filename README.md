# 古树病原鉴定与保护放行台

本项目为古树保护机构提供从树皮样本封签、交接、病原实验，到风险复核、复检和保护放行凭据核验的完整工作台。服务采用 Go 分层单体架构与 SQLite 本地事务持久化，浏览器页面由同一服务提供。

工作台同时提供案卷状态/风险/树木编号/更新时间组合检索、风险统计、复检幂等留痕及放行凭据撤销与公开核验。

## 构建、运行与测试

```text
go test ./...
go run . -selfcheck -addr=127.0.0.1:19081
go run . -addr=127.0.0.1:19081
```

启动后访问 `http://127.0.0.1:19081/`。也可以通过 `PORT` 环境变量指定端口，服务只绑定回环地址。
